# Data Structures & Algorithms — Study Notes

My personal study notes for Data Structures & Algorithms, written in simple words with examples and practice questions. I keep updating this repo as I study each lecture.

## Topics covered
1. Introduction to Data Structures & Algorithm Analysis (Big-O, Omega, Theta)
2. Arrays — insertion, deletion, searching
3. Linked Lists — singly linked list, insert/delete at start, middle and end
4. Stacks — push, pop, peek; applications
5. Queues — enqueue, dequeue; circular queue
6. Trees — binary trees and traversals (inorder, preorder, postorder)
7. Graphs — BFS and DFS
8. Sorting & Searching — bubble, selection, insertion, binary search
9. Hashing — hash functions and collision handling

## What is inside
- `NOTES.md` — the quick revision cheat sheet (read this before an exam)
- More topic files will be added lecture by lecture.
